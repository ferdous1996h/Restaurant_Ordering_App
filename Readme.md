# Resturant_Ordering_App

## Feature

- Can add item from menu to cart
- can remove item from cart
- Dynamic cost calculation
- Popup modal for order confirmation
- Thank U screen
- Dark mode feature with LocalStorage

## Skill acquired

- Use event delegation for instant event response
- Object mutation and render data according to that
- avoid multiple eventloop
- Implement darkmode in localstorage to keep darkmode status in browser
